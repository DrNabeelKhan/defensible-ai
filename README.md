## Companion artifacts

Two artifacts named as in preparation inside these specifications, the
**gate record templates** for the Five-Gate Deployment Model and the **MESA
assessment instrument**, are not in this release. When they ship they will be
published here and made callable over MCP at
[mcp.nabeelkhan.com/api/mcp](https://mcp.nabeelkhan.com/api/mcp), which serves
the contents of these specifications to an agent without a key.
